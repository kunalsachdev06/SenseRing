# Earlier AS5600 prototype

`SmartRing_AS5600_Firmware.ino` is preserved from the earlier repository as a historical reference. It uses the previous rotary-input arrangement and is **not** the firmware for the current touch ring or website.

Use `../Firmware/SenseRing_Touch/SenseRing_Touch.ino` with its accompanying headers for the present TTP223 + tactile-button build. Do not mix the legacy gesture labels, mode behaviour or pin assumptions with the touch release.
